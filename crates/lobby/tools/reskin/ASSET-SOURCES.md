# Asset sources

Every image and sound in this fork is CC0 (public domain) or generated in-repo.
Nothing here carries a NonCommercial term, so the fork can ship inside a
commercial GameNight build.

This replaced the upstream Fish Folk media, which is **CC BY-NC 4.0** and
therefore could not. The code is untouched and remains dual MIT / Apache-2.0.

free to use in personal, educational and commercial projects."* Attribution is
optional for all of the above; we credit them in `CREDITS.md` anyway.

Note that the 2D Guns archive itself contains no licence file — the CC0 grant is
on its OpenGameArt page, so that page is the record to keep.

## Fonts were not touched

`assets/ui/FairfaxSM.ttf` and `assets/ui/ark-pixel-16px-latin.ttf` are both
**SIL Open Font License 1.1**, which permits commercial bundling. They were
never part of the problem and are unchanged.

## Rebuilding

The scripts read from CC0 packs downloaded to `/tmp/cc0` and write in place.
They need Pillow and (for the silent music placeholder) ffmpeg.

```
python3 -m venv /tmp/cc0/venv && /tmp/cc0/venv/bin/pip install Pillow
cd tools/reskin
/tmp/cc0/venv/bin/python build_players.py
/tmp/cc0/venv/bin/python build_tiles.py
/tmp/cc0/venv/bin/python build_props.py
/tmp/cc0/venv/bin/python build_audio.py
/tmp/cc0/venv/bin/python build_devpack.py
```

The builders preserve every atlas grid declared in `*.atlas.yaml` and every
non-atlas image's pixel dimensions, so no gameplay or layout YAML had to change.
`tile_roles.py` derives each tile index's structural role from how the shipped
levels use it, which is what keeps the maps readable after the swap.

## Faces are a layer, not part of the body

The CC0 characters ship with eyes and mouth painted into the body art. That is
wrong for GameNight, where a player's face is their identity, so `faces.py`
wipes the painted face off every pose and redraws the features as chunky pixel
art on jumpy's `face` layer — the swappable slot the engine already had.

The face atlases are one column per expression and one row per variant
(11 x 8). `deal_player_faces_system` in `src/gamenight.rs` picks the row from a
hash of the player's id, so everyone is dealt a face that stays put until they
sign in; at that point `swap_player_faces_system` removes the layer and their
own drawn avatar takes its place. `FACE_VARIANTS` and `FACE_COLUMNS` are
duplicated in `build_players.py` and `gamenight.rs` and must agree.

Note the face layer is not colour-tinted with the player's colour, so eye whites
stay white against the tinted skin.

## Known gaps

- **No music.** Kenney has no background tracks — its "Music Jingles" are
  0.4-1.8s stings against the 80-163s loops upstream shipped. Every music slot
  in `game.yaml` points at a 10s silent placeholder and the twelve NC tracks are
  deleted. A soundtrack is its own commissioning job.
- **`ship_decorations` indices 52-54** are capped surface tiles by majority vote
  but appear mid-block in `level_1`, so a couple of decorative seams read as
  stray highlights. Cosmetic only.
- **Names still reference the old identity.** Skin folders (`fishy`, `sharky`,
  `pescy`, `orcy`) and several hats (`pufferfish`, `spicy_lobster`, `water_lily`)
  keep Fish Folk's naming. Those are identifiers, not media, so they carry no
  licence risk — but they should be renamed before the lobby is presented as
  ours.
