# GameNight reference lobby

Build from the repository root with `python scripts/run-local.py`.
This is a separate Rust workspace. Its Bones source dependency is vendored
under `vendor/bones`; no additional checkout is required.

Press a controller button to join. Jump on the Start button to play the next
game; Back/Select returns to the lobby. Scan a character QR when the optional
local studio is enabled to edit that character's name and avatar.
