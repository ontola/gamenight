# Gamepad Party for Unreal Engine

Start with the [Unreal integration guide](../../docs/site/unreal.md), published
in [Gamepad Party Docs](https://gamenight.ontola.io/docs/unreal). The demo game
[Dash Derby](../../examples/unreal-demo) uses every part of the plugin.

- `GameNight/` is the plugin. Copy it into your project's `Plugins/` folder,
  or list this folder in your `.uproject` under `AdditionalPluginDirectories`.
  Unreal Engine 5.3 or later; Windows, macOS and Linux.
- `GameNight/Source/GameNight/Public/GameNightSubsystem.h` is the whole API, for
  C++ and Blueprint.
- `GameNightCore.h/.cpp` is the protocol core in plain C++17 (no engine
  headers, no exceptions, no RTTI). Other C++ engines can wrap it the same way.
- `GameNightProtocol.h` is generated by `scripts/build-protocol.py` from
  `contract/protocol.schema.json`. Do not edit it.
- `tests/` holds the core's unit tests and a headless game for the conformance
  harness:

```sh
python3 scripts/test-unreal-sdk.py --headless /tmp/unreal-core
cargo run -p gamenight-certify -- unreal-core -- /tmp/unreal-core
```

CI has no Unreal build: the module and the demo are not compiled there. Build
the demo with a real engine and playtest it under Gamepad Party before a release.
