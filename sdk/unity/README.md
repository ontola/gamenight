# GameNight for Unity

The Unity package for [GameNight](https://github.com/ontola/gamenight): the
party lifecycle, every player's controller by seat, names, colours and faces,
match settings, phone buttons, requests in plain words, phone screens, saved
progress, the room log, rumble and the game window.

Install it from **Window → Package Manager → + → Add package from git URL**:

```text
https://github.com/ontola/gamenight.git?path=/sdk/unity
```

The guide is [docs/site/unity.md](../../docs/site/unity.md), published at
`/docs/unity` on the GameNight site. The reference game is Orb Rush in
[examples/unity-demo](../../examples/unity-demo).

- `Runtime/Core`: plain C#, no UnityEngine. The connection, lifecycle, input,
  settings, saves and faces. `Protocol.cs` is generated by
  `scripts/build-protocol.py`; do not edit it.
- `Runtime/Unity`: `GameNight` (pumps the client every frame), `GameNightScreen`
  (window, sound and frame rate) and `GameNightFaces` (faces as textures).
- `Tests~`: dotnet projects for CI, ignored by Unity. Run
  `python3 scripts/test-unity-sdk.py`.

After adding or renaming a file, run `python3 scripts/unity-package-meta.py`:
a package installed from git needs a `.meta` file next to every file.
