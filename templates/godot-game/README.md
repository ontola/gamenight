# Template Game

A couch game for [Gamepad Party](https://gamenight.ontola.io). Everyone races for
orbs; A dashes and knocks others aside; a round lasts 60 seconds.

Controls: left stick moves, A dashes. Without Gamepad Party: WASD and Space, or
any controller. Run it with Godot 4.5:

    godot --path . -- --players 2

See [AGENTS.md](AGENTS.md) for tests, screenshots and releases.
