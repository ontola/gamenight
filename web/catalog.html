The catalog lives in the public repository. Each game has a JSON entry with its player count, artwork, downloads and integration details.

Submission guide See existing entries

Show the game people will play.

Use a cover, a small icon and a screenshot from the game. State the supported player counts and platforms. Link to a versioned download with its checksum.

Submit the entry through a pull request. The catalog guide documents the fields and validation commands.

Be clear about what works.

Starting a game is different from a full integration. Report the checks you've run, including pause and resume, controller assignment and shutdown. Test profile colours and drawn faces separately.

Missing support should be visible in the catalog. Read about integration →
