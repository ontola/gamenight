# Shared GameNight web UI

Public build output and page assets for the local and hosted Studio. The Svelte + TypeScript application shell lives in `web-app/`. Run `pnpm install --frozen-lockfile`, `pnpm check`, and `pnpm build` there after shell changes. The build updates `web/shell.js`, which is committed so Rust builds and pinned cloud imports need no Node runtime. The local Rust server embeds these files. The private deployment vendors a pinned snapshot using its import script; do not edit that generated snapshot.

Home, catalog and Studio use client-side navigation. Their DOM/controllers mount once and remain available until a full reload, preserving drawings, undo history and catalog filters. `studio.js` retains the canvas/editor behavior behind the Svelte shell; it is scoped rather than publishing global variables. The catalog remains a private page mounted through the same router. Styling is external for the hosted CSP. Room/navigation state is owned by the shared Svelte store, with adapters reporting connection changes. Auth, downloads and QR URLs carrying a new controller claim still use full navigation deliberately.
